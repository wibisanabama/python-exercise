# Python Exercise

Repository ini berisi kumpulan latihan pemrograman Python untuk mempelajari sintaks dasar, percabangan, perulangan, fungsi, struktur data, algoritma, dan penyelesaian studi kasus sederhana.

## Struktur Proyek

| Direktori | Isi |
| --- | --- |
| `dasar` | Latihan dasar Python dan operasi aritmetika. |
| `dicoding` | Latihan materi Python dari Dicoding. |
| `exercise` | Program latihan interaktif. |
| `function` | Latihan pembuatan dan penggunaan fungsi. |
| `geometri` | Perhitungan luas, keliling, dan volume bangun geometri. |
| `ipas` | Perhitungan energi mekanik dan listrik. |
| `json` | Pengolahan data berformat JSON. |
| `kasus` | Penyelesaian studi kasus sederhana. |
| `kondisi` | Latihan logika kondisi dan validasi. |
| `lambda` | Implementasi perhitungan menggunakan fungsi lambda. |
| `leet` | Latihan penyelesaian soal algoritma. |
| `logic` | Latihan algoritma dan logika pemrograman. |
| `looping` | Latihan perulangan. |
| `praktek` | Kumpulan latihan praktik. |
| `program` | Latihan runtunan, percabangan, dan pengulangan. |
| `tes` | Skrip pengujian dan percobaan. |
| `ujian` | Kumpulan penyelesaian soal ujian. |

## Persyaratan

- Python 3
- Tidak memerlukan dependensi pihak ketiga

## Menjalankan Program

Jalankan skrip yang dipilih dari root repository:

```bash
python path/to/script.py
```

Contoh:

```bash
python exercise/calculator.py
python logic/konversi_bilangan_romawi.py
python program/percabangan/menentukan_tahun_kabisat.py
```

Sebagian besar skrip menggunakan input melalui terminal. Ikuti instruksi yang ditampilkan saat program dijalankan.

## Tujuan

Repository ini digunakan sebagai dokumentasi proses belajar dan referensi implementasi konsep dasar Python.
